# social

Private working repo for building in public: a rolling build log across all my
personal projects, plus drafted posts and the screenshots/clips that go with them.

## Layout

| Path | What |
|---|---|
| `BUILD-LOG.md` | Append-only, newest first. One entry per unit of work: project, timestamp, what changed, why it matters, whether it's shareable. Written by the `social-log` skill (hook-triggered after every commit). |
| `voice.md` | Tone guide + example posts. Read by `social-draft` every run. Hand-edited. |
| `config.json` | Personal-projects root + per-project `public`/`private` overrides. |
| `drafts/` | `YYYY-Www.md` — weekly drafted posts with shot lists. Generated by `social-draft`. Never auto-posted. |
| `assets/` | `YYYY-MM-DD-<project>-<slug>/` — one folder per shareable moment. `SHOT-LIST.md` says what to capture; screenshots/mp4s dropped in later. Also the home for App Store screenshots. |
| `posted/` | Copies of things actually shipped to Threads/X. Grows into few-shot voice examples. |
| `log/` | Year archives once `BUILD-LOG.md` gets long. |

## How it runs

1. **Capture** — a global `PostToolUse` hook (`social-log/hooks/post-commit-capture.sh`)
   fires after every commit in any personal project, appends a stub to
   `BUILD-LOG.md`, and nudges Claude to enrich it. Skill: `social-log`.
2. **Compose** — run `/social-draft` (weekly). It reads the log for the window,
   sweeps `git log` across all repos as a backstop, reads `voice.md`, and writes
   `drafts/YYYY-Www.md`. Skill: `social-draft`.

Skills + hook source live in
`~/sites/personal-projects/Skills/agent-skills/social/`. See that folder's
`social-log/install.md` for setup.
